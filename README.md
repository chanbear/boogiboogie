# 노인 일자리 알리미 — 팀 애플파이

안산시 노인일자리 신청 접근성 지원 웹 앱. 자세한 배경·문제 정의·기능 목록은 `PROJECT_BRIEF.md`와 실제 작업 저장소의 `CLAUDE.md`를 참고.

# 프로젝트 실행 방법

**⚠️ `public/index.html` 파일을 직접 더블클릭해서 열면 절대 안 됩니다.** 이 앱은 실제 Express+SQLite 백엔드에 API로 데이터를 요청하는 앱이라(정적 HTML 목업이 아님), `file://`로 열면 서버가 없어서 "서버에 연결할 수 없습니다" 화면만 뜹니다.

**심사·확인용 (추천)**: 아래 배포 주소를 브라우저에서 그냥 열면 됩니다. 설치·서버 실행 전혀 필요 없음.

```
https://ilja-alrimi-server.onrender.com
```

**로컬 개발용**:
1. `boogiboogie/server` 폴더에서 `npm install` 후 `npm start` (Node.js 22.5 이상 필요, `node:sqlite` 내장 모듈 사용)
2. 브라우저에서 `http://localhost:3000` 접속 (파일 더블클릭 아님, 반드시 서버를 먼저 실행한 뒤 이 주소로 접속)

# 프로젝트 유형

서비스형 프로젝트로 시작했으나, 실제로는 공공데이터를 다음과 같이 기능에 직접 반영했다.

- 안산시 노인·독거노인 인구수, 노인일자리현황(경기도 31개 시군), 노인실태조사, 건강보험공단 노인인구 통계 → 공공데이터 확인 화면의 통계·그래프·표
- 안산시청·안산시니어클럽 실제 연락처·운영시간 → 고객센터 화면
- OpenStreetMap Nominatim으로 조회한 8개 일자리 실좌표 → 일자리 위치 지도
